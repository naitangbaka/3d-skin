# 架构设计文档

## 一、技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | Vue 3 + TypeScript | 用户指定 |
| 构建工具 | Vite | Vue 3 最佳搭配 |
| UI 库 | @oreui-web/vue | 用户指定，Minecraft 风格 UI，引入方式 `npm install @oreui-web/vue` |
| 3D 渲染 | @daidr/minecraft-skin-renderer | 用户指定 |
| 状态管理 | Pinia | Vue 3 官方推荐 |
| 图标 | SVG（本地/Iconify） | 按 frontend-dev 规范 |
| 类型校验 | Zod（可选） | 按 type-safety 规范 |

> 本项目为纯前端工具，无后端服务。

## 三、关键类型设计

```typescript
// src/types/skin.ts

// 皮肤来源类型
export const SkinSourceType = {
  UPLOAD: 'upload',
  API: 'api'
} as const;

export type SkinSourceType = typeof SkinSourceType[keyof typeof SkinSourceType];

// 皮肤数据
export interface SkinData {
  id: string;
  sourceType: SkinSourceType;
  imageUrl: string;      // 皮肤图片 DataURL / BlobURL
  originalName?: string; // 原始文件名
  playerName?: string;   // 玩家名（API获取时）
}

// 效果参数
export interface EffectParams {
  scale: number;         // 缩放 0.5 - 2.0
  outline: boolean;      // 描边开关
  outlineIntensity: number; // 描边强度 0 - 1
  outlineColor: string;  // 描边颜色
  glow: boolean;         // 发光开关
  glowIntensity: number; // 发光强度 0 - 1
  glowColor: string;     // 发光颜色
}

// 背景设置
export const BackgroundType = {
  COLOR: 'color',
  TRANSPARENT: 'transparent'
} as const;

export type BackgroundType = typeof BackgroundType[keyof typeof BackgroundType];

export interface BackgroundSettings {
  type: BackgroundType;
  color: string;         // 背景色（默认 #FFFFFF）
}

// 导出设置
export interface ExportSettings {
  width: number;
  height: number;
  format: 'png';         // 仅 PNG
  transparent: boolean;  // 是否透明背景
}

// Mojang API 响应
export interface MojangProfileResponse {
  id: string;
  name: string;
  properties: Array<{
    name: string;
    value: string;
  }>;
}
```

## 四、状态管理设计（Pinia）

```typescript
// src/stores/skinStore.ts

import { defineStore } from 'pinia';
import { ref, computed } from 'vue';
import type { SkinData, EffectParams, BackgroundSettings, ExportSettings } from '@/types';

export const useSkinStore = defineStore('skin', () => {
  // State
  const skin = ref<SkinData | null>(null);
  const effects = ref<EffectParams>({
    scale: 1.0,
    outline: false,
    outlineIntensity: 0.5,
    outlineColor: '#000000',
    glow: false,
    glowIntensity: 0.5,
    glowColor: '#ffffff'
  });
  const background = ref<BackgroundSettings>({
    type: 'color',
    color: '#ffffff'
  });
  const exportSettings = ref<ExportSettings>({
    width: 512,
    height: 512,
    format: 'png',
    transparent: false
  });

  // Getters
  const hasSkin = computed(() => skin.value !== null);
  const isTransparent = computed(() => background.value.type === 'transparent');

  // Actions
  function setSkin(data: SkinData) { skin.value = data; }
  function updateEffects(params: Partial<EffectParams>) { Object.assign(effects.value, params); }
  function updateBackground(settings: Partial<BackgroundSettings>) { Object.assign(background.value, settings); }
  function updateExport(settings: Partial<ExportSettings>) { Object.assign(exportSettings.value, settings); }
  function resetEffects() { /* 重置为默认值 */ }

  return {
    skin, effects, background, exportSettings,
    hasSkin, isTransparent,
    setSkin, updateEffects, updateBackground, updateExport, resetEffects
  };
});
```

## 六、关键交互设计

| 交互 | 实现方式 |
|------|----------|
| 鼠标拖拽旋转 | 监听 `mousedown`/`mousemove`/`mouseup`，计算 delta 旋转模型 |
| 滚轮缩放 | 监听 `wheel`，调整 renderer 的 camera distance |
| 左侧参数调整 | 实时同步到 renderer，使用 `requestAnimationFrame` 优化 |
| 摄像机拍摄 | `canvas.toDataURL('image/png')` 或 renderer 的截图 API |
| 弹窗下载 | 创建 `<a download>` 触发下载 |
