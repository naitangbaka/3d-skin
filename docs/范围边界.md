# 范围边界文档

## 做什么

- 在线3D皮肤预览与截图工具
- 支持自定义上传皮肤文件和API获取皮肤
- 提供视觉效果调整（缩放、描边、发光）
- 支持背景更换和透明背景
- 支持鼠标交互（拖拽旋转、滚轮缩放）
- 支持截图导出为PNG，自定义分辨率

## 不做什么

- 不支持多人模型展示
- 第一版本不支持移动端适配
- 第一版本不支持动画
- 不涉及皮肤编辑/绘制功能（仅预览和截图）
- 不涉及用户系统、登录注册
- 不涉及皮肤分享、社区功能

## 边界说明

- 皮肤文件格式：仅支持标准 `.png` 格式
- API来源：Mojang官方API
- 导出格式：仅PNG
- 默认分辨率：512x512
- 分辨率范围：用户自定义输入，不做上限限制（由浏览器性能决定）
