# 规则清单

## 已确认

### 技术栈
- 前端框架：Vue 3 + TypeScript
- 构建工具：Vite
- UI库：@oreui-web/vue（`npm install @oreui-web/vue`）
- 3D渲染库：@daidr/minecraft-skin-renderer
- 状态管理：Pinia

### 布局规则
- 左侧：效果控制区域（缩放、描边、发光）
- 右侧：模型展示区域
- 模型右上角：摄像机按钮

### 功能规则
- 背景默认纯白色
- 支持透明背景选项
- 拍摄后弹窗，用户可选择下载或返回
- 导出格式：PNG
- 默认分辨率：512x512
- 分辨率由用户自定义输入长和宽

### 交互规则
- 支持鼠标拖拽旋转模型
- 支持滚轮缩放模型
- 左侧效果区域提供参数调整

### 数据来源
- 支持自定义上传 `.png` 皮肤文件
- 支持通过玩家用户名从 Mojang API 获取皮肤
