# 需求清单

## 功能拆解与优先级（MoSCoW）

### Must（必须）

| 编号 | 功能 | 说明 |
|------|------|------|
| M1 | 皮肤导入 | 支持上传自定义 `.png` 皮肤文件 |
| M2 | API获取皮肤 | 通过玩家用户名从 Mojang API 获取皮肤 |
| M3 | 3D模型展示 | 右侧区域展示3D皮肤模型 |
| M4 | 鼠标拖拽旋转 | 支持鼠标拖拽旋转模型视角 |
| M5 | 滚轮缩放 | 支持滚轮缩放模型 |
| M6 | 缩放模型 | 左侧效果区域提供缩放控制 |
| M7 | 增加描边 | 左侧效果区域提供描边效果开关/强度控制 |
| M8 | 增加发光效果 | 左侧效果区域提供发光效果开关/强度控制 |
| M9 | 背景更换 | 支持更换背景颜色，默认纯白色 |
| M10 | 透明背景 | 支持选择透明背景 |
| M11 | 摄像机拍摄 | 模型右上角摄像机按钮，点击后拍摄当前画面 |
| M12 | 拍摄弹窗 | 拍摄后弹出弹窗，展示预览图 |
| M13 | 下载截图 | 弹窗内提供下载按钮，导出为 PNG 格式 |
| M14 | 返回操作 | 弹窗内提供返回按钮，关闭弹窗回到编辑界面 |
| M15 | 自定义分辨率 | 导出时支持用户自定义输入长和宽，默认 512x512 |
| M16 | UI布局完善 | 左侧效果控制区 + 右侧模型展示区，布局合理美观 |

| S2 | 动画支持 | 后续版本考虑 |
