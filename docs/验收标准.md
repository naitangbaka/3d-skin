# 验收标准

## 功能验收

### 皮肤导入（M1）
- [ ] 用户可以通过文件选择器上传 `.png` 皮肤文件
- [ ] 上传后模型正确渲染
- [ ] 非PNG文件给出错误提示

### API获取皮肤（M2）
- [ ] 用户可以输入玩家用户名
- [ ] 点击获取后从Mojang API拉取皮肤
- [ ] 用户名不存在时给出错误提示

### 3D模型展示（M3）
- [ ] 模型正确渲染在右侧区域
- [ ] 模型比例正确，无变形

### 鼠标拖拽旋转（M4）
- [ ] 按住鼠标左键可拖拽旋转模型
- [ ] 旋转流畅，无卡顿

### 滚轮缩放（M5）
- [ ] 鼠标滚轮可缩放模型
- [ ] 缩放范围合理，有最小/最大限制

### 缩放模型（M6）
- [ ] 左侧有缩放控制滑块/输入框
- [ ] 调整参数实时影响模型大小

### 增加描边（M7）
- [ ] 左侧有描边效果开关
- [ ] 开启后模型边缘有描边效果
- [ ] 支持调整描边强度/颜色

### 增加发光效果（M8）
- [ ] 左侧有发光效果开关
- [ ] 开启后模型有发光效果
- [ ] 支持调整发光强度/颜色

### 背景更换（M9）
- [ ] 支持选择背景颜色
- [ ] 默认背景为纯白色

### 透明背景（M10）
- [ ] 支持选择透明背景
- [ ] 透明背景导出PNG时保留透明通道

### 摄像机拍摄（M11）
- [ ] 模型右上角有摄像机按钮
- [ ] 点击后捕获当前画面

### 拍摄弹窗（M12）
- [ ] 拍摄后弹出弹窗
- [ ] 弹窗内展示预览图

### 下载截图（M13）
- [ ] 弹窗内有下载按钮
- [ ] 点击后下载PNG图片
- [ ] 图片质量清晰

### 返回操作（M14）
- [ ] 弹窗内有返回按钮
- [ ] 点击后关闭弹窗，回到编辑界面

### 自定义分辨率（M15）
- [ ] 弹窗内或导出前支持输入长和宽
- [ ] 默认值为512x512
- [ ] 输入非数字时给出错误提示

### UI布局完善（M16）
- [ ] 左侧效果区域布局合理
- [ ] 右侧模型展示区域布局合理
- [ ] 整体UI美观，间距合理
- [ ] 使用 mcui-oreui 风格

## 技术验收

- [ ] 项目使用 Vue + TypeScript
- [ ] 类型安全，无 `any` 滥用
- [ ] 使用 mcui-oreui 作为UI库
- [ ] 使用 @daidr/minecraft-skin-renderer 作为3D渲染库
